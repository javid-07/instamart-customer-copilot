
# Instamart Customer Intelligence & Support Copilot

## Overview

This project builds a customer intelligence and support copilot using synthetic data. It includes data cleaning, customer segmentation, lapse prediction, ticket triage, policy question answering and refund processing.

## Reproduce

1. Clone the repository and enter the project folder.
2. Create a virtual environment using Python 3.11 or newer.
3. Activate the virtual environment.
4. Install dependencies from `requirements.txt`.
5. Run `python generate_data.py` to generate the raw synthetic data.
6. Run the Part A cleaning, database, validation, SQL analysis and pandas analysis scripts.
